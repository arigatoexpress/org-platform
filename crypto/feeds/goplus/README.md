# GoPlus / Honeypot Safety Connector

Status: scaffolded.

Use GoPlus and Honeypot.is for token contract safety checks once chain IDs and contract addresses are present in the scoring input. The first vertical slice only scores CoinGecko trending IDs, so contract-level safety is a follow-up.
